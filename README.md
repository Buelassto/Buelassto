### 🧠 Methodology (How I Hunt)

1. **Scope Deep-Dive** — Read every disclosed report on the program. Understand their stack.
2. **Recon at Scale** — Subdomains → live hosts → tech stack → endpoints → parameters
3. **Attack Surface Mapping** — Auth flows, IDOR candidates, state-changing endpoints
4. **Manual Testing** — Business logic, authz, race conditions, injection points
5. **Automate Repetition** — Custom nuclei templates, Python one-liners for scale
6. **Document Everything** — Reproducible PoC, impact analysis, remediation suggestions

### 📜 Rules of Engagement
